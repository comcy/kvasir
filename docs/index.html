mimirlink

Offline-first developer workflow & journaling tool — terminal native.

Python 3.11+ Linux · macOS · Windows No internet required Plain files (NDJSON + Markdown)

Install

🐧 Linux & macOS 
curl -sSL https://comcy.github.io/kvasir/install.sh | bash
🪟 Windows — PowerShell 
irm https://comcy.github.io/kvasir/install.ps1 | iex

Requires Python 3.11+. The installer installs uv automatically if not present, then builds mimirlink from source. No account or package registry needed.

Quick start

mimirlink workspace create private   # set up your first workspace
mimirlink tui                        # launch the terminal UI
mimirlink --help                     # full command reference

What it does

  • Bullet-journal TUI with calendar navigation
  • Todo manager with priorities, tags & due dates
  • Full-text search across notes and todos
  • Bidirectional sync between Markdown checkboxes and todos
  • Work session tracking (git hook based)
  • Conventional Commits validator + recorder
  • Custom metrics (manual + auto from sessions/commits)
  • Live query blocks inside Markdown notes

Advanced install options

# With PDF export support (needs system libs: Cairo, Pango)
uv tool install "git+https://github.com/comcy/kvasir.git" --extra pdf

# Install a specific commit or branch
uv tool install "git+https://github.com/comcy/kvasir.git@main"

# Update to latest
uv tool upgrade mimirlink

# Uninstall
uv tool uninstall mimirlink
