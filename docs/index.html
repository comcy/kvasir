kvasir

Terminal-Tool für Git-Worktrees: Überblick über mehrere Repos, schnell wechseln, neue Worktrees anlegen, sicher aufräumen. Linux, macOS, Windows. Befehle: kvasir oder kurz kv.

GitHub · README

Voraussetzungen

  • git ab 2.36
  • Optional für PR-, Issue- und Pipeline-Anzeige (GitHub): gh installiert und angemeldet (gh auth login).
  • Python 3.11+ besorgt der Installer bei Bedarf selbst über uv.

Installation

Linux / macOS

curl -LsSf https://comcy.github.io/kvasir/install.sh | sh

Windows (PowerShell)

irm https://comcy.github.io/kvasir/install.ps1 | iex

Das Skript installiert uv (falls nicht vorhanden) und danach kvasir direkt aus GitHub. Kein Paketregister, kein Konto. Wird kvasir nicht gefunden: Terminal neu starten oder uv tool update-shell. Aktualisieren: Skript erneut ausführen oder uv tool upgrade kvasir.

Ohne Skript:

uv tool install "git+https://github.com/comcy/kvasir"

Schnellstart

# Repo im Bare-Layout klonen und registrieren
kvasir setup https://github.com/comcy/kvasir

# oder ein vorhandenes Repo registrieren
kvasir setup ~/Workspace/mein-repo

# Übersicht öffnen
kvasir tui

setup fragt nach Branch-Vorlagen, Fetch-Intervall und dem Befehl zum Öffnen eines Terminals. Später ändern: kvasir setup <pfad> --reconfigure. Konfigurationsort anzeigen: kvasir config.

TUI

Drei Spalten: Repos, Worktrees/Branches, Details.

↑ ↓Auswahl
h / lSpalte links / rechts
EnterTerminal im Worktree öffnen
nNeuen Worktree anlegen
xWorktree entfernen (verweigert bei ungesicherter Arbeit)
fAlle Repos fetchen
pMarkierten Worktree pullen (--ff-only)
mNotiz zum Worktree/Branch
bRemote-Branches ein-/ausklappen
uGitHub-Daten (PR, Work Item, Pipelines) aktualisieren
iGesamtansicht: meine PRs, Review-Anfragen, Pipeline-Läufe
rNeu laden
qBeenden

Pull passiert nie automatisch. Die GitHub-Anzeige ist rein lesend.

Konfiguration

Zwei Dateien: repos.toml (pro Remote-URL Branch-Vorlagen, fetch_interval, platform_interval; kann synchronisiert werden) und local.toml (pro Rechner lokaler Pfad je Repo und open_command).

Linux / macOS~/.config/kvasir/ (bzw. $XDG_CONFIG_HOME/kvasir/)
Windows%APPDATA%\kvasir\
ÜberschreibenUmgebungsvariable KVASIR_CONFIG_DIR

Branch-Vorlagen mit {type}, {id}, {slug}, {date}, z. B. {type}/{slug} oder features/{id}-{slug}. open_command ersetzt {path}; Standard Windows wt.exe -d {path}, sonst kitty --directory {path}.
